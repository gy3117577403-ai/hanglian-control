## Manual checks before any future deployment

- Confirm API image tag uses `v3.12-<SHA>` or `sha-<SHA>`.
- Confirm Tablet image tag uses `v3.12-<SHA>` or `sha-<SHA>`.
- Confirm no `latest`, `production`, or `stable` tag is used.
- Confirm API has one persistent volume mounted at `/data/hanglian`.
- Confirm Tablet has no business persistent volume.
- Confirm CORS points to the actual Tablet domain only after the user approves deployment.
- Confirm no real credential is written in this file.
