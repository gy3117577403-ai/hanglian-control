# 现场统计看板使用指南

## 打开方式

在平板主界面顶部点击“演示工具”，选择“现场统计”。需要当前 Mock 角色具备 `analytics.view` 权限。

## 筛选

顶部支持：

- 今日 / 本周 / 本月 / 全部
- 全部 / 前段 / 后段 / 通用

切换后看板会重新加载所有统计数据。

## 指标解释

- 计划数：当前筛选范围内的生产计划数量。
- 生产中：执行状态为生产中的计划数量。
- 已完工：执行状态或计划状态已完成的数量。
- 异常停线：执行状态为异常停线的数量。
- 完成率：完成数量除以计划数量。
- 不良率：不良数量除以完成数量。
- 资料待复核：资料状态为待确认或相关 readiness 待复核。
- 文件缺失：资料状态缺失或上传文件记录缺失。
- 知识待复核：治具、异常、质量标准中非有效或待复核项。

## 图表

看板使用 ECharts 展示：

- 计划状态环图。
- 完成率趋势折线图。
- 不良率趋势折线图。
- 异常类别柱状图。
- 资料问题排行条形图。
- 知识库状态分布图。

无数据时显示清晰提示，不会白屏。

## 复制摘要

点击“复制统计摘要”会调用 `GET /api/analytics/summary-text`，并尝试写入剪贴板。若浏览器限制自动复制，会保留摘要文本供手动复制。
