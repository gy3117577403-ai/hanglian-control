# 生产执行闭环现场使用指南

本指南用于 V2.5 演示版的安卓平板横屏验收。系统仍为 Mock 演示环境，所有执行记录写入本地 metadata 或内存，不连接真实数据库。

## 推荐走查流程

1. 打开平板主界面，确认顶部版本为 V2.5。
2. 在左侧选择一个今日计划。
3. 查看开工资料检查、现场知识验证和资料完整度。
4. 打开“现场执行闭环”区域。
5. 点击“开工检查”，确认检查项是否可开工。
6. 点击“开始生产”，计划状态进入生产中。
7. 点击“过程确认”，提交首件确认或巡检确认。
8. 点击“数量报工”，提交本次完成数量、良品、不良和说明。
9. 如需模拟异常，点击“异常停线”，填写原因。
10. 点击“恢复生产”，继续执行。
11. 点击“完工确认”，填写完工数量与说明。
12. 点击“班组交接”，生成交接记录。
13. 点击“现场日报”，查看汇总和日报文本。

## 状态说明

| 状态 | 说明 |
| --- | --- |
| `not_started` | 计划尚未进入执行 |
| `ready_to_start` | 开工检查通过或基本满足开工条件 |
| `running` | 正在生产 |
| `paused` | 人为暂停，等待恢复 |
| `exception_hold` | 异常停线，需要处理 |
| `completed` | 计划已完工 |
| `cancelled` | 计划已取消，当前演示版不提供前端取消入口 |

## 注意事项

- 当前不接 Sealos PostgreSQL。
- 当前不接企业微信微盘。
- 当前不接真实语音识别。
- 不要上传真实客户资料。
- 不要提交本地 metadata JSON。
- 不要在聊天窗口、文档或代码中写入真实数据库连接串。

## 后续落地建议

真实落地时优先替换 `execution.service` 的数据来源，将执行记录、状态事件、报工记录、交接记录写入 PostgreSQL，并保留当前 DTO、权限和前端组件结构。
