# 现场试运行指南

## 试运行前准备

1. 确认电脑与安卓平板在同一局域网。
2. 执行 `npm run dev:lan`，使用终端输出的平板访问地址。
3. 打开“演示工具 -> 系统配置中心”。
4. 配置前段、后段、资料维护和演示平板工位。
5. 打开“演示工具 -> 试运行检查”，确认得分和提醒项。

## 前段平板

- 工位：前段组长平板。
- 默认角色：前段组长。
- 默认范围：今日计划。
- 重点检查：前段参数、开工资料检查、SOP、资料确认。

## 后段平板

- 工位：后段组长平板。
- 默认角色：后段组长。
- 重点检查：连接器、装配说明、孔位图、成品细节图、现场知识。

## 资料维护平板

- 工位：资料维护平板。
- 默认角色：资料维护。
- 重点检查：导入中心、资料维护中心、复核队列、版本状态。

## 使用反馈

入口：演示工具 -> 使用反馈。

用于反馈软件试运行问题，例如：

- UI 显示不清楚。
- 权限看不到入口。
- 预览速度慢。
- 网络提示不明确。
- 操作流程容易误解。

生产异常仍走原有“异常反馈”流程。

## 公告通知

顶部公告条显示当前有效公告。关闭状态保存在浏览器 localStorage，不影响生产操作。

## 收集问题

试运行结束后导出或截图以下内容：

- 使用反馈列表。
- 试运行检查结果。
- 现场角色和工位配置。
- 平板型号、浏览器、横屏分辨率。

当前版本不连接 Sealos、不连接企业微信微盘、不接真实语音。
