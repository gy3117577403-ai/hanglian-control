# 导入模板说明

演示导入文件可通过以下命令生成：

```bash
npm run demo:imports
```

输出目录为 `demo-import-files`，所有文件均为假客户、假产品、假资料，不包含真实客户资料。

## 生产计划

字段：计划日期、周计划编号、销售、客户、产品编号、产品名称、产品版本、工序段、计划数量、完成数量、生产状态、负责人、备注。

校验：

- 计划日期、客户、产品编号、产品名称、工序段、计划数量必填。
- 工序段必须是：前段、后段、通用。
- 计划数量和完成数量必须是数字，完成数量为空默认 0。
- 生产状态必须是：待生产、生产中、已完成、异常，空则默认待生产。
- 产品版本为空默认 Rev.A，负责人为空默认组长演示账号。

## 客户产品

字段：销售、客户、产品编号、产品名称、产品版本、产品类别、备注。

校验：

- 客户、产品编号、产品名称必填。
- 产品版本为空默认 Rev.A。
- 同客户 + 产品编号视为同一产品，重复导入提示警告并更新基础资料。

## 前段参数

字段：客户、产品编号、产品版本、裁线长度、剥皮长度、端子型号、拉力标准、压接高度、图纸版本、参数状态、备注。

校验：

- 客户、产品编号必填。
- 裁线长度、剥皮长度、端子型号、拉力标准、压接高度至少应有 3 项。
- 参数状态必须是：当前有效、待确认、已失效、不一致，空则默认待确认。
- 图纸版本为空默认 Rev.A。
- 找不到产品时，预览提示应用导入时会自动创建基础产品。

## 后段资料包

字段：客户、产品编号、产品版本、连接器型号、连接器装配说明书、插接孔位图、作业流程SOP、成品细节图数量、图纸版本、SOP版本、资料状态、备注。

校验：

- 客户、产品编号必填。
- 连接器型号缺失会提示警告。
- 插接孔位图、作业流程SOP、成品细节图至少应有 1 项。
- 成品细节图数量必须是数字，空则默认 0。
- 资料状态必须是：当前有效、待确认、已失效、不一致，空则默认待确认。

## 常见错误

- 表头改名：请保持模板第一行中文字段不变。
- 数量写成中文大写：请填写阿拉伯数字。
- 工序段写成“总装”：请改为前段、后段或通用。
- 状态值不在允许范围：请按模板说明填写。
- 导入真实客户资料：当前阶段禁止，请只使用演示数据。
