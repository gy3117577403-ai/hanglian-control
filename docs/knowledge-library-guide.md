# 现场知识库使用说明

## 三类知识

- 治具库：治具编号、名称、类型、适用工位、使用方法、点检标准、保养周期、状态。
- 异常库：异常编号、标题、工位、类别、现象、原因、处理方法、预防措施、严重度、状态。
- 质量标准库：标准编号、标题、检验项目、标准值、公差、检验方法、抽检规则、缺陷等级、状态。

## 平板现场使用

组长进入 `/tablet` 后选择生产计划。现场知识区会按当前计划和产品加载四个区域：

- 知识验证：显示现场知识得分、阻塞项、待复核项和推荐动作。
- 关联治具：显示当前产品 / 工序可用治具、待复核治具和点检要求。
- 常见异常：显示 high / critical 异常作为班前提醒。
- 质量标准：显示 effective、pending_review、expired 标准状态。

快捷操作区支持：

- 打开现场知识
- 查看关联治具
- 查看常见异常
- 查看质量标准
- 复制知识摘要

## 开工检查联动

V2.4 将现场知识验证并入开工资料检查：

- 缺少关联治具会阻塞。
- 治具无启用状态或缺少点检标准会提示复核。
- high / critical 异常会作为班前提醒。
- 缺少有效质量标准会阻塞或提示复核。
- expired 质量标准显示红线提醒。

## 维护中心使用

资料维护、工艺、品质或管理员可打开“资料维护中心 -> 现场知识库”：

- 治具库支持单条维护和批量状态 / 工序维护。
- 异常库支持单条维护和批量状态 / 严重度 / 工序维护。
- 质量标准库支持单条维护和批量状态 / 缺陷等级 / 工序维护。
- 批量操作前有确认提示。
- 维护记录写入本地 `knowledge-records.json`，并产生审计留痕。

## 导入使用

生成演示导入文件：

```bash
npm run demo:knowledge
```

会生成：

- `demo-knowledge-files/demo-fixtures.xlsx`
- `demo-knowledge-files/demo-abnormal-cases.xlsx`
- `demo-knowledge-files/demo-quality-standards.xlsx`

在导入中心选择对应类型后上传、预览、应用。V2.4 预览会加强字段校验，包括状态、工序、严重度、缺陷等级、治具点检标准和质量标准有效性提醒。

## 安全边界

当前仍为本地 Mock / metadata：

- 不连接 Sealos PostgreSQL。
- 不接企业微信微盘。
- 不接真实语音识别。
- 不上传真实客户资料。
- 不执行数据库连接或写库操作。

后续接 Sealos 时，优先替换 `KnowledgeService` 的数据来源为 Prisma Repository，并把 metadata 数据迁移为正式表数据。
