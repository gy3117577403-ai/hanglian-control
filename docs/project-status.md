# 项目状态

当前版本：V1.2 本地开发完成准备中。

## 已完成能力概览

- V0.1：完成平板端生产计划资料管控原型、Mock 数据和基础后端 Mock API。
- V0.2：前端改为优先通过后端 Mock API 获取数据，并保留离线演示 fallback。
- V0.3：完善资料上传、预览、查询留痕和异常反馈基础流程。
- V0.4：整理数据库接入准备结构，但未连接真实数据库。
- V0.5：实现本地文件资料管理和资料预览占位能力。
- V0.6：实现资料版本管理、版本红线、审计记录和本地 metadata。
- V0.7：补充 Prisma Repository 草稿、迁移预演和 seed dry-run 准备。
- V0.8A：完成 Sealos PostgreSQL 测试库只读验证准备，但当前不连接真实数据库。
- V0.9：完成本地安全基线检查与首次提交准备。
- V1.0：完成暖色方向的初步 UI 优化。
- V1.1：完成暖色立体工业平板 UI 重构，引入 PrimeVue、GSAP、AutoAnimate、Embla。
- V1.2：强化资料预览体验、资料操作弹窗和旧深色组件清理。

## 当前状态

- 当前前端仍优先使用后端 Mock API，并保留离线演示。
- 当前后端仍为 NestJS Mock / 本地原型服务。
- 当前不连接 Sealos PostgreSQL。
- 当前不接企业微信微盘。
- 当前不接真实语音识别平台。
- 当前不保存真实密钥、真实客户资料或真实生产图纸。
- 当前资料预览使用本地占位和组件结构，为后续真实文件接入做准备。

## 下一阶段建议

- 进入 V1.3 或 V1.0 UI 复核阶段，继续做现场平板交互细节和视觉打磨。
- 后续在测试库连接串准备好后，再按只读流程验证 Sealos PostgreSQL。
- 企业微信微盘同步、真实语音识别、数据库写入和真实文件资料应继续作为独立阶段推进。
