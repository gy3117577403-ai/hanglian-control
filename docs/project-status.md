- 企业微信微盘未接入。
- 企业微信登录未接入。
- 真实语音识别未接入。
- Sealos PostgreSQL 未连接，未执行写库。

## 安全状态

- `.env.local` 不提交。
- 本地上传文件不提交。
- metadata JSON 不提交。
- 真实 DATABASE_URL 不写入代码、文档或日志。
- 本阶段禁止执行 `db:readonly-check`、`prisma migrate`、`prisma db push`、`prisma db seed`、`prisma:seed:test-db`。
