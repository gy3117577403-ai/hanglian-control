## 平板访问方法

电脑和平板在同一局域网时，使用终端输出的 `http://<电脑IPv4>:5173/tablet` 访问平板端。API 地址为 `http://<电脑IPv4>:3000/api`。

## 建议验收流程

1. 切换六类 Mock 角色。
2. 检查生产计划、资料查询、PDF / 图片预览、版本历史和文件健康。
3. 检查导入中心、资料维护、复核队列和维护历史。
4. 检查治具库、异常库、质量标准库和知识验证。
5. 检查开工、过程确认、报工、暂停、恢复、异常停线、完工、班组交接和日报。
6. 检查统计看板与复制摘要。
7. 打开“演示工具 -> 全流程总验收”，复制验收报告。
