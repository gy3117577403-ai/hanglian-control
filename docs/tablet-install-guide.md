# 安卓平板安装与局域网演示指南

## 本地电脑启动

在项目根目录执行：

```bash
npm run dev:lan
```

终端会显示平板访问地址。电脑和平板需要在同一 WiFi 或同一网段。

## Windows 一键启动

可以双击：

```text
start-field-demo.bat
```

或在 PowerShell 中执行：

```powershell
.\start-field-demo.ps1
```

脚本只启动局域网演示，不连接数据库，不执行写库操作。

## 平板访问

在安卓平板浏览器访问：

```text
http://电脑IPv4:5173/tablet
```

API 地址通常为：

```text
http://电脑IPv4:3000/api
```

## 添加到桌面

方式一：在系统内打开“演示工具 → 安装到平板桌面”。

方式二：使用浏览器菜单：

1. 打开浏览器菜单。
2. 选择“添加到主屏幕”或“安装应用”。
3. 回到桌面，从图标进入系统。

## PWA 限制说明

局域网 HTTP 演示环境可能只支持添加桌面快捷方式，部分浏览器不会显示完整 PWA 安装按钮。完整 PWA 安装建议后续使用 HTTPS 部署环境。

## 横屏使用

- 推荐横屏。
- 1280 x 800 及以上体验更好。
- 如果竖屏打开，系统会提示“建议横屏使用，以获得完整的车间资料管控视图”。

## 常见问题

### 平板打不开页面

- 检查电脑和平板是否在同一 WiFi。
- 检查终端输出的 IPv4 地址是否正确。
- 检查 Windows 防火墙是否允许 Node.js。

### API 离线

- 确认 `npm run dev:lan` 正在运行。
- 打开“演示工具 → 网络诊断”查看 API 地址。

### 防火墙拦截

- 允许 Node.js 通过 Windows 防火墙。
- 确认前端 5173 和 API 3000 端口可访问。

### PWA 安装按钮不出现

- 局域网 HTTP 下属于常见限制。
- 可以使用浏览器菜单“添加到主屏幕”。
- 后续 HTTPS 部署后体验更完整。

### PDF 预览失败

- 使用 `demo-upload-assets` 下的演示 PDF。
- 如果浏览器不支持在线预览，可下载后查看。

### 图片预览失败

- 使用 `demo-upload-assets` 下的演示图片。
- 检查“文件健康”状态是否提示文件缺失或不支持。
