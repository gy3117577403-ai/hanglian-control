# 平板端 UI 指南

## 风格定位

平板端采用暖色、立体、清晰的工业控制台风格。目标不是黑色科技风，而是适合车间组长横屏操作的高可读界面。

## 布局原则

- 优先适配 1280x800、1366x768、1920x1200。
- 顶部状态栏显示系统名、日期、班组、角色、用户、API/离线状态和现场模式。
- 左侧用于生产计划、搜索、语音模拟、锁定产品和最近查询。
- 右侧用于当前计划、资料齐套性、前段/后段资料、文件预览和版本状态。

## 现场模式

现场模式会：

- 放大关键按钮和资料卡片。
- 减少迁移/开发入口。
- 保留 Mock、未接 Sealos、离线演示等安全提示。
- 支持尝试进入浏览器全屏，失败时不报错。

## V1.5 现场面板

- 顶部状态栏提供“网络诊断”和“现场走查”两个触控入口。
- 网络诊断弹窗适配 1280x800，展示访问模式、前端地址、API Base、健康状态、延迟、数据源、文件健康、Swagger 和混合内容风险。
- 现场走查弹窗使用 17 项手动 checklist，进度条和勾选状态保存在本机 `localStorage`。
- 两个弹窗都必须可滚动，底部按钮不能被遮挡。

## V1.6 演示辅助面板

- 顶部状态栏新增“系统信息”和“演示说明”入口。
- 系统信息面板必须明确显示 V1.6 演示版、Mock 数据源、Sealos 未接入、企业微信微盘未接入、真实语音未接入。
- 演示说明面板按“启动演示、选择生产计划、查看资料、上传与追溯”四步展示，不写成长篇说明。
- 面板可以提供复制摘要、打开网络诊断、打开现场走查、打开上传资料等触控按钮。
- 重置演示界面状态必须二次确认，并明确不会删除上传资料或审计记录。

## V1.7 演示工具菜单

- 顶部状态栏将演示辅助入口集中到“演示工具”菜单，避免顶部按钮过多。
- 菜单项包括系统信息、演示说明、网络诊断、现场走查、演示数据管理、演示前检查、演示资料说明、后续路线、迁移预览和重置演示界面状态。
- “现场模式”必须保持独立按钮，便于平板现场快速切换。
- 演示数据管理、演示前检查、演示资料说明和后续路线面板都使用暖色立体卡片，避免黑色科技风。
- 所有演示管理入口必须明确显示未接 Sealos、未接企业微信微盘、未接真实语音，不提供真实授权或写库入口。

## 空状态和错误状态

- 空状态使用 `WarmEmptyState`，强调下一步操作。
- 错误状态使用 `WarmErrorState`，只显示简体中文的现场可理解文案。
- 不展示英文技术错误、大段堆栈或内部异常对象。
- 适用场景包括无计划、无搜索结果、无资料、无审计记录、无版本历史、文件健康无数据、网络诊断失败和预览失败。

## 触控规则

- 主按钮不低于 48px。
- 次级按钮不低于 44px。
- 上传区域必须足够大。
- 弹窗底部按钮在 1366x768 下必须可见。
- 标签页可横向滚动，避免 1280 宽度下挤压。
- 长文本允许省略，但关键资料标题、版本和状态必须可见。

## 资料预览

- PDF、SOP、孔位图、成品图保持“真实资料台”的视觉。
- 无资料、演示资料、文件缺失、不支持格式、加载失败、历史版本、待确认版本和大文件都要有明确中文提示。
- 新上传资料高亮 3 秒，便于组长确认已进入资料包。
- 资料预览台展示当前资料诊断卡：`previewUrl`、`downloadUrl`、`manual_upload`、`mock`、`canPreview` 和建议动作。

## 安卓平板适配

- 顶部状态栏在 1280 宽度下允许信息分两行，不压缩按钮文本。
- 标签页保持横向滚动或换行，不能依赖 hover。
- 上传弹窗内容可滚动，footer 按钮保持可见。
- Toast 放在右上角，不遮挡底部确认、上传、反馈按钮。

## 颜色语义

- 绿色：可预览、有效、完成。
- 琥珀色：待确认、需复核、大文件、重复版本提醒。
- 暖红色：异常、失效、文件缺失、预览失败。
- 蓝灰色：Mock 或演示资料。
