# 平板端 UI 指南

## V1.1 风格定位

V1.1 将平板端从黑色科技风调整为“暖色立体工业控制台”。界面面向车间组长的横屏安卓平板，重点是看得清、点得准、状态边界明确、资料风险醒目。

## 视觉原则

- 主背景使用象牙白、砂岩、暖琥珀和浅铜色，不使用大面积纯黑、slate-950、霓虹蓝紫或赛博渐变。
- 页面分区使用清晰的 1px 暖棕边界、内高光和外阴影，形成可辨识的面板层级。
- 主要按钮使用立体按压效果，保留明显的顶部高光、底部厚度和触控反馈。
- 状态颜色保留语义：绿色表示有效/完成，琥珀表示待确认/需复核，红色表示异常/失效/版本红线。
- 字体以大字号、高字重为主，关键数据优先显示，不在卡片内堆叠说明文字。

## 布局原则

- 优先适配横屏平板：1280x800、1366x768、1920x1200。
- 顶部为车间中控状态栏，显示系统名、日期、班组、角色、用户、API/离线模式。
- 主体保持两栏：左侧约 1/3 为计划和查询，右侧约 2/3 为当前任务、工序参数和资料预览。
- 左侧计划卡片突出计划状态、资料完整度、确认状态和当前锁定产品。
- 右侧使用“当前任务头 + 工序参数台 + 资料预览台”的工作台结构。

## 组件使用

V1.1 开始引入并使用 PrimeVue：

- Button：主要操作、次要操作、资料管理操作。
- Tag：生产状态、确认状态、资料状态、数据源状态。
- Panel/Card：工序参数、资料分区和弹窗内容承载。
- Tabs：今日/本周切换、图纸/SOP/孔位图/成品图切换。
- Dialog：异常反馈、上传资料、版本管理、审计记录、迁移预览。
- InputText、Textarea、Select：搜索、反馈、上传资料表单。
- ProgressBar、Message、Toast、ConfirmDialog：资料完整度、红线提醒、操作提示。

shadcn-vue 仍保留在项目中，后续可用于特定轻量组件，但 V1.1 主界面优先使用 PrimeVue。

## 动效原则

- GSAP 只用于轻量入场和语音按钮呼吸动效，避免影响平板性能。
- @formkit/auto-animate 用于计划列表、搜索结果、检查项和记录列表的自然过渡。
- Embla Carousel 用于资料卡片横向浏览，适配平板滑动。
- 动效只使用 transform 与 opacity，避免布局抖动。

## 资料预览原则

- 当前仍使用本地 Mock 占位预览，不使用远程图片或远程 PDF。
- 预览区域需要像真实资料台：显示文件类型、标题、版本、状态、来源和占位内容。
- 后续接入 `vue-pdf-embed` 与 `viewerjs` 时，应替换预览内容区，不改变外层资料台布局。
