# 平板端 UI 指南

## V1.2 风格定位

平板端采用“暖色立体工业控制台”风格，面向线束车间前段/后段组长横屏使用。界面重点不是炫技，而是现场可读、可点、可判断：计划状态要醒目，资料版本风险要明显，PDF/SOP/孔位图/成品细节图预览要像真实资料台。

V1.2 继续避免回到大面积黑色科技风，不使用霓虹蓝紫主视觉，也不使用远程图片或远程 PDF。

## 视觉原则

- 主背景使用象牙白、砂岩、暖琥珀、浅铜和柔和工业灰。
- 卡片使用清晰边界、内高光、轻微投影和立体按钮反馈。
- 状态色保持固定语义：绿色表示有效/完成，琥珀表示待确认/需复核，红色表示异常/失效/版本红线。
- 关键数据使用大字号和高字重，说明文字保持短句。
- 资料完整度、确认状态、版本状态优先靠颜色、图标和标签表达。

## 布局原则

- 优先适配横屏安卓平板：1280x800、1366x768、1920x1200。
- 顶部状态栏表现为车间中控台，显示系统名、日期、班组、角色、用户和 API/离线模式。
- 主体保持左右两栏：左侧是计划、搜索和锁定产品，右侧是任务详情、工序参数和资料预览。
- 资料预览区采用“资料夹标签 + 资料卡片轮播 + 主预览台”的结构。
- 弹窗尺寸控制在平板屏幕内，表单、版本列表和审计时间线都要便于触控。

## 组件使用

V1.2 主界面优先使用 PrimeVue 与 Tailwind CSS：

- Button：主要操作、资料管理、预览缩放、确认动作。
- Card/Panel：资料台、参数区、弹窗内容承载。
- Tabs：计划切换、资料夹切换。
- Tag：生产状态、确认状态、资料状态、数据源状态。
- ProgressBar/Meter：资料完整度、上传模拟进度。
- Dialog：上传资料、版本档案、版本对比、审计记录、迁移预览。
- Menu/SplitButton：资料卡片操作菜单。
- FileUpload：本地资料选择模拟，不上传真实客户资料。
- Timeline：资料审计记录。
- Toast/ConfirmDialog：成功提示和重要操作确认。

shadcn-vue 生成组件保留在项目中作为轻量基础组件库，但 V1.2 已清理旧深色业务组件，当前平板主流程不再依赖旧黑色后台式界面。

## 动效原则

- GSAP 用于页面关键区域入场、资料预览区域切换和语音按钮反馈，保持轻量。
- AutoAnimate 用于计划列表、搜索结果、资料卡片、版本档案、审计记录等列表的自然过渡。
- Embla Carousel 用于资料卡片横向滑动浏览，适配平板手势。
- 动效尽量使用 transform 和 opacity，避免布局抖动。

## 资料预览原则

- PDF 预览结构已经接入 `vue-pdf-embed` 和 `pdfjs-dist`，真实文件未上传时显示本地演示图纸占位。
- 图片/SOP/孔位图/成品图预览接入 `viewerjs`，真实文件未上传时显示本地生成的资料占位图。
- 所有资料卡片必须显示标题、类型、版本、状态、来源、更新时间和操作入口。
- 历史/失效版本显示红线提醒，待确认版本显示复核提醒。
- 当前阶段不读取远程资源，不展示真实客户资料。
