# 平板端 UI 指南

## 风格

V0.1 使用深色工业中控风，强调车间现场的清晰度、状态感和低误触。

## 布局

- 优先适配安卓平板横屏：`1280x800`、`1366x768`、`1920x1200`
- 顶部为固定状态栏
- 主体为两栏结构：左侧约 1/3，右侧约 2/3
- 左侧用于计划选择和查询，右侧用于资料查看和操作确认

## 颜色原则

- 深色底：降低现场强光干扰
- 青色：当前主操作、在线状态、资料主线
- 绿色：有效、已确认、完成
- 黄色：待确认、需复核
- 红色：异常、失效、版本红线

## 交互原则

- 按钮高度尽量大于 44px，适合触控
- 关键状态使用文字、颜色和图标三重提示
- 搜索、语音占位、确认、异常反馈都在首屏可见
- 文件预览当前使用本地 Mock 占位器，后续替换为真实 PDF 和图片预览组件

## 组件使用

当前使用 shadcn-vue 的 Button、Badge、Progress、Tabs、Dialog、Textarea、Sonner 等组件，并结合 lucide-vue-next 图标。
