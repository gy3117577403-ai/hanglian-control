# 平板端 UI 指南

## 风格定位

平板端采用暖色、立体、清晰的工业控制台风格。目标不是黑色科技风，而是适合车间组长横屏操作的高可读界面。

## 布局原则

- 优先适配 1280x800、1366x768、1920x1200。
- 顶部状态栏显示系统名、日期、班组、角色、用户、API/离线状态和现场模式。
- 左侧用于生产计划、搜索、语音模拟、锁定产品和最近查询。
- 右侧用于当前计划、资料齐套性、前段/后段资料、文件预览和版本状态。

## 现场模式

现场模式会：

- 放大关键按钮和资料卡片。
- 减少迁移/开发入口。
- 保留 Mock、未接 Sealos、离线演示等安全提示。
- 支持尝试进入浏览器全屏，失败时不报错。

## V1.5 现场面板

- 顶部状态栏提供“网络诊断”和“现场走查”两个触控入口。
- 网络诊断弹窗适配 1280x800，展示访问模式、前端地址、API Base、健康状态、延迟、数据源、文件健康、Swagger 和混合内容风险。
- 现场走查弹窗使用 17 项手动 checklist，进度条和勾选状态保存在本机 `localStorage`。
- 两个弹窗都必须可滚动，底部按钮不能被遮挡。

## 触控规则

- 主按钮不低于 48px。
- 次级按钮不低于 44px。
- 上传区域必须足够大。
- 弹窗底部按钮在 1366x768 下必须可见。
- 标签页可横向滚动，避免 1280 宽度下挤压。
- 长文本允许省略，但关键资料标题、版本和状态必须可见。

## 资料预览

- PDF、SOP、孔位图、成品图保持“真实资料台”的视觉。
- 无资料、演示资料、文件缺失、不支持格式、加载失败、历史版本、待确认版本和大文件都要有明确中文提示。
- 新上传资料高亮 3 秒，便于组长确认已进入资料包。
- 资料预览台展示当前资料诊断卡：`previewUrl`、`downloadUrl`、`manual_upload`、`mock`、`canPreview` 和建议动作。

## 安卓平板适配

- 顶部状态栏在 1280 宽度下允许信息分两行，不压缩按钮文本。
- 标签页保持横向滚动或换行，不能依赖 hover。
- 上传弹窗内容可滚动，footer 按钮保持可见。
- Toast 放在右上角，不遮挡底部确认、上传、反馈按钮。

## 颜色语义

- 绿色：可预览、有效、完成。
- 琥珀色：待确认、需复核、大文件、重复版本提醒。
- 暖红色：异常、失效、文件缺失、预览失败。
- 蓝灰色：Mock 或演示资料。
