# V0.1 功能范围

## 定位

V0.1 是“线束车间生产计划资料管控系统”的可运行原型，面向安卓平板横屏使用，服务对象是前段组长和后段组长。

## 核心流程

生产计划 -> 选择客户/产品任务 -> 自动加载产品资料包 -> 前段/后段资料查看 -> 版本确认 -> 查询留痕 -> 异常反馈。

## 页面结构

- `/` 自动跳转到 `/tablet`
- `/tablet` 为平板主界面
- 顶部状态栏：系统名称、日期、班组、角色、网络状态、当前用户
- 左侧计划区：今日/本周计划、计划列表、模糊搜索、语音查询占位、当前锁定产品、最近查询
- 右侧资料区：任务详情、资料完整度、前段/后段切换、资料卡片、文件预览标签页、版本提醒、确认和异常反馈

## 数据流

- 前端 Mock 数据位于 `apps/tablet/src/mock/production-data.ts`
- 前端状态由 `apps/tablet/src/stores/production-store.ts` 管理
- 后端 Mock API 使用 `apps/api/src/common/mock-production-data.ts`
- 当前前端优先使用本地 Pinia Mock 数据，`services/api.ts` 已预留后续接后端接口

## 验收重点

- 平板横屏深色工业中控风
- 搜索、切换、确认、反馈、语音模拟等关键交互可用
- `npm run build` 可通过
- 不连接真实数据库、企业微信微盘或语音平台
