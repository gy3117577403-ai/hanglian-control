# V0.5 本地文件资料上传与预览

## 阶段目标

V0.5 在不连接真实数据库、企业微信微盘、对象存储和语音平台的前提下，实现“本地文件资料上传、产品绑定、真实 PDF/图片预览、资料状态参与齐套性判断”的闭环原型。

## 已实现范围

- 后端新增 `documents` 模块，提供资料查询、上传、状态更新、版本更新和归档接口。
- 后端新增 `files` 模块，通过受保护的文件流接口读取 `storage/uploads` 内的本地文件。
- 后端新增 `storage` 模块，负责本地上传目录、元数据文件和安全文件名。
- 上传文件支持 PDF、JPG、PNG、WEBP，单文件限制 30MB。
- 上传资料来源标记为 `manual_upload`，元数据写入 `apps/api/storage/metadata/documents.json`。
- 计划详情、搜索、资料齐套性检查会合并 seed Mock 资料和本地上传资料。
- 如果同类有效的本地上传资料存在，齐套性检查优先使用本地上传资料。
- `pending_review` 会产生复核提醒，`expired`、`missing`、`inconsistent` 会阻断或触发红线提醒。
- 前端资料区域支持上传弹窗、PDF iframe 预览、图片预览、占位预览、状态标记和归档。

## 前端数据流

1. 页面选择生产计划。
2. Store 调用 `/api/production-plans/:id` 获取计划详情。
3. Store 调用 `/api/documents?planId=...&productId=...` 获取资料列表。
4. 上传资料时提交 `multipart/form-data` 到 `/api/documents/upload`。
5. 上传成功后刷新计划详情、资料列表和齐套性状态。
6. 资料预览通过 `/api/files/:storedFileName` 读取后端本地文件流。
7. 修改资料状态后刷新当前计划，并重新计算资料复核提示。

## 本地存储目录

- 上传文件：`apps/api/storage/uploads`
- 元数据目录：`apps/api/storage/metadata`
- 元数据文件：`apps/api/storage/metadata/documents.json`

以上目录仅用于本机开发原型，不作为正式生产文件存储方案。

## 当前仍为 Mock

- 生产计划、客户、产品、资料包基础数据仍来自 Mock Repository。
- 组长确认、异常反馈、查询留痕仍为内存或本地 Mock 行为。
- Prisma Repository 仍是后续接 Sealos PostgreSQL 的适配层骨架。
- 企业微信微盘、对象存储、OCR、语音识别仍未接入。
- 未执行 Prisma migrate、db push 或真实 seed。
