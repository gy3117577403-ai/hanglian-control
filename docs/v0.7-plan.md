# V0.7 Sealos PostgreSQL 测试库接入准备

## 阶段目标

V0.7 不连接真实数据库，不执行迁移，不写入测试库。目标是把后续 Sealos PostgreSQL 测试库接入前的代码结构、安全闸门、Prisma repository 草案和 Mock 数据迁移预演准备好。

## 已完成范围

- 新增数据库安全闸门：`DATA_SOURCE`、`DB_TARGET`、`ALLOW_TEST_DB_CONNECT`、`ALLOW_PRISMA_WRITE`、`ALLOW_DESTRUCTIVE_DB_ACTIONS`。
- 新增系统状态接口：`GET /api/system/database-safety`。
- PrismaService 改为懒加载，默认 Mock 模式不会实例化 Prisma Client 或打开连接池。
- ProductionPlan、Product、Document、Search、Feedback、Audit、Migration 的 Prisma Repository 草案已实现。
- 新增 Mock/metadata 到 Prisma seed 结构的 dry-run 映射器与校验器。
- 新增命令：`migration:validate`、`migration:preview`、`prisma:seed:dry-run`、`prisma:seed:test-db`。
- 前端迁移预览弹窗新增数据库安全状态、迁移校验结果和 seed dry-run 统计。

## 明确未做

- 未连接真实 Sealos PostgreSQL。
- 未执行 `prisma migrate dev/deploy`。
- 未执行 `prisma db push`。
- 未执行真实 `prisma db seed`。
- 未接企业微信微盘、语音识别、对象存储。

## 数据流状态

默认仍是：

前端 → NestJS Mock API → Mock Repository / 本地 metadata

仅当后续显式配置测试库并打开安全开关后，才会进入：

前端 → NestJS API → Prisma Repository → Sealos PostgreSQL 测试库

## 安全原则

- `DATA_SOURCE=mock` 时禁止连接数据库。
- `DB_TARGET=production` 时禁止数据库读写。
- 未设置 `ALLOW_TEST_DB_CONNECT=true` 时禁止 Prisma 读取。
- 未设置 `ALLOW_PRISMA_WRITE=true` 时禁止 Prisma 写入。
- 未设置 `ALLOW_DESTRUCTIVE_DB_ACTIONS=true` 时禁止危险数据库操作。
