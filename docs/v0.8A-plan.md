# V0.8A Sealos PostgreSQL 测试库只读验证

## 阶段目标

V0.8A 只做 Sealos PostgreSQL 测试库只读连通验证、数据库安全检查、迁移 SQL 预览和文档完善。

本阶段不建表、不导入数据、不执行迁移、不执行 `db push`、不执行 seed。

## 为什么只做只读验证

测试库接入前需要先确认连接串、SSL、网络和数据库版本是否可用。只读验证可以降低误连生产库、误建表、误写入的风险。

允许的 SQL 仅限：

- `SELECT 1 AS ok`
- `SELECT current_database()`
- `SELECT current_schema()`
- `SELECT version()`

## 数据库安全变量

`apps/api/.env.example` 默认保持安全关闭：

```env
DATA_SOURCE=mock
DB_TARGET=local
ALLOW_TEST_DB_CONNECT=false
ALLOW_PRISMA_WRITE=false
ALLOW_DESTRUCTIVE_DB_ACTIONS=false
DATABASE_SSL_MODE=require
DATABASE_CONNECT_TIMEOUT_SECONDS=10
```

只有测试库只读检查时，才在本机创建 `apps/api/.env.local`，并设置：

```env
DATA_SOURCE=mock
DB_TARGET=test
ALLOW_TEST_DB_CONNECT=true
ALLOW_PRISMA_WRITE=false
ALLOW_DESTRUCTIVE_DB_ACTIONS=false
```

不要提交 `.env.local`，不要填写生产库连接串。

## 如何执行只读检查

```bash
npm run db:readonly-check -w api
```

如果没有真实 `apps/api/.env.local`，脚本会安全退出并提示缺少测试库配置，不会导致整体失败。

## 如何生成迁移 SQL 预览

```bash
npm run prisma:migration:sql-preview -w api
```

输出文件：

```text
apps/api/storage/metadata/prisma-migration-preview.sql
```

该 SQL 仅为预览，尚未执行到数据库。

## 为什么不执行 migrate / db push / seed

V0.8A 的目的不是改动数据库，而是验证接入条件和迁移脚本形状。真实建表和导入必须在 V0.8B 单独执行，并且需要再次确认测试库、备份和安全开关。

## 进入 V0.8B 的条件

- 只读连接检查成功。
- 迁移校验无错误。
- seed dry-run 无错误。
- 迁移 SQL 预览已人工检查。
- 确认目标库是 Sealos PostgreSQL 测试库，不是生产库。
