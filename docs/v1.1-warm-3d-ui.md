# V1.1 暖色立体工业平板 UI 重构

## 目标

V1.1 的目标是提升平板端视觉质量，将原有深黑科技风调整为更适合车间现场的暖色立体工业控制台，同时保持 V0.9/V1.0 已有 Mock API 数据流和安全边界。

## 本阶段完成内容

- 引入 PrimeVue、@primeuix/themes、primeicons、tailwindcss-primeui。
- 引入 @formkit/auto-animate、GSAP、embla-carousel-vue。
- 新增 PrimeVue 安装插件 `apps/tablet/src/plugins/primevue.ts`。
- 新增暖色主题样式 `apps/tablet/src/styles/warm-control-theme.css`。
- 重构平板主界面为暖色工作台：
  - 顶部车间中控状态栏。
  - 左侧计划队列与搜索/语音查询台。
  - 当前锁定产品卡片。
  - 右侧当前任务头和资料完整度台。
  - 前段/后段参数台。
  - 图纸/SOP/孔位图/成品图资料预览台。
  - 异常反馈、上传资料、版本管理、审计记录、迁移预览 PrimeVue 弹窗。

## 视觉系统

- 主色：象牙白、砂岩、暖琥珀、浅铜色。
- 辅助色：绿色用于有效和完成，红色用于失效和异常，少量冷色只用于数据源/信息状态。
- 组件质感：面板使用边界、内高光、投影；按钮使用立体厚度和按压反馈。
- 禁用方向：不使用大面积纯黑、深蓝 slate 背景、霓虹蓝紫、赛博发光风格。

## 数据流保持

V1.1 不改变数据来源策略：

- 前端仍优先访问后端 Mock API。
- 后端不可用时仍使用前端本地 Mock fallback。
- 资料上传仍为本地开发原型。
- 迁移预览仍为 dry-run/只读展示，不连接真实数据库。

## 安全边界

本阶段没有执行以下操作：

- 未连接 Sealos PostgreSQL。
- 未执行 Prisma migrate、db push、seed。
- 未执行 `db:readonly-check`。
- 未接企业微信微盘。
- 未接真实语音识别。
- 未 push 到 GitHub。

## 后续建议

- 进入 V1.2 后可继续优化资料预览真实度，替换为真实 PDF/图片预览组件。
- 对 1280x800、1366x768、1920x1200 三个尺寸持续做视觉回归。
- 将旧 shadcn 深色组件逐步迁移到 PrimeVue 暖色组件，减少重复 UI 体系。
