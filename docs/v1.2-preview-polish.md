# V1.2 资料预览与平板交互打磨

## 阶段目标

V1.2 聚焦“真实资料预览体验 + 旧组件清理 + 平板细节打磨”。本阶段不接真实数据库、不接企业微信微盘、不接真实语音识别，也不上传真实客户资料。

## 已完成范围

- 资料夹切换：图纸、SOP、孔位图、成品图、连接器资料、流程卡按资料类型分组。
- PDF 预览：接入 `vue-pdf-embed` 与 `pdfjs-dist` 的结构；未上传真实 PDF 时显示本地演示图纸占位。
- 图片预览：接入 `viewerjs`，支持 SOP、孔位图、成品图等资料的放大查看入口。
- 资料卡片轮播：使用 Embla Carousel 实现横向资料卡片浏览。
- 资料操作菜单：支持查看版本、设为当前有效、查看审计、对比版本、标记待确认、标记失效和归档。
- 上传弹窗：使用 PrimeVue FileUpload 做本地选择模拟，增加文件类型、版本、状态、流程段和说明校验。
- 版本档案：区分当前有效版本、待确认版本、历史/失效版本。
- 版本对比：支持选择两个版本并展示关键字段差异。
- 审计时间线：使用 PrimeVue Timeline 展示资料操作记录。
- 迁移预览：保持弱化状态，只展示 Mock 预演信息，不提供真实迁移执行入口。
- 旧组件清理：移除 V0.x 深色后台风业务组件，保留当前暖色平板主流程。

## 组件与交互

- PrimeVue：Button、Card、Tabs、Tag、ProgressBar、Dialog、Menu、FileUpload、Timeline、Toast、ConfirmDialog。
- GSAP：用于页面/资料预览区域轻量动效。
- AutoAnimate：用于列表和弹窗内容变化。
- Embla：用于资料卡片横向滑动。
- ViewerJS：用于图片类资料预览放大。
- vue-pdf-embed/pdfjs-dist：用于后续真实 PDF 预览。

## 安全边界

- 未新增大型依赖。
- 未连接 Sealos PostgreSQL。
- 未执行 db:readonly-check。
- 未执行 migrate、db push、seed 或任何写库命令。
- 未接企业微信微盘。
- 未接真实语音平台。
- 未提交 `.env.local`、真实上传文件或本地 metadata JSON。

## 验收重点

- `npm run security:check` 通过。
- `npm run build` 通过。
- `npm run check` 通过。
- 1280x800、1366x768、1920x1200 横屏下无明显遮挡、溢出或回到黑色科技风。
