# V1.3 现场交互与文件健康

## 阶段目标

V1.3 不是大换风格，而是在 V1.2 暖色立体工业平板基础上，强化现场可用性、触控细节、文件流健康检查和资料预览兜底。

## 现场操作步骤

新增现场步骤提示：

1. 选择生产计划
2. 锁定客户产品
3. 检查资料齐套
4. 查看图纸 / SOP / 参数
5. 组长确认
6. 异常反馈，若需要

步骤状态使用暖色语义：完成为绿色，当前为橙色，需复核为黄色，异常阻塞为红色。

## 快捷操作区

新增现场快捷操作：

- 查看前段参数
- 查看后段资料
- 打开图纸
- 打开 SOP
- 查看孔位图
- 上传资料
- 组长确认
- 异常反馈

快捷操作使用 PrimeVue Button，保持 44px 以上触控高度，并根据当前前段/后段模式突出常用按钮。

## 文件健康检查

新增只读接口：

`GET /api/documents/file-health?planId=xxx&productId=xxx`

该接口不连接数据库，不修改 metadata，不删除文件，只判断资料是否为演示资料、可预览、文件缺失、预览异常或不支持预览。

## 预览兜底体验

- PDF 预览失败时显示标题、版本、资料状态、文件健康状态、失败说明、下载和重新加载入口。
- 图片预览失败时显示健康状态、上传真实图片和重新加载入口。
- 演示资料明确提示“当前为演示资料”，上传真实资料后自动替换预览。

## 平板触控复核

- 主按钮高度不低于 44px。
- 重要按钮接近或超过 48px。
- 卡片间距保持 12px 左右。
- 弹窗底部按钮可触控。
- 右侧内容纵向滚动，不产生横向滚动。
- 上传、版本、审计、迁移弹窗保持平板尺寸内可用。

## 动效复核

- 计划列表继续使用 AutoAnimate。
- 资料卡片继续使用 AutoAnimate + Embla。
- 版本历史继续使用 AutoAnimate。
- 语音按钮继续使用 GSAP 呼吸动效。
- 主页面进入仍使用 GSAP 轻量入场。
- 按钮保留 active 下压反馈，卡片保留 hover 抬起。

## 当前边界

- 仍未接 Sealos PostgreSQL。
- 仍未接企业微信微盘。
- 仍未接真实语音识别。
- 仍不上传真实客户资料。
- 仍不执行 migrate、db push、seed 或任何写库操作。
