# V1.4 上传与预览复测说明

## 阶段目标

V1.4 聚焦“真实文件上传体验复测、文件预览边界用例、平板现场操作细节收口”。本阶段仍然不连接 Sealos PostgreSQL、不接企业微信微盘、不接真实语音平台，只强化本地 Mock API 与本地文件流原型。

## 新增脚本

- `npm run demo:assets`：生成安全演示资料到 `demo-upload-assets`。
- `npm run file-flow:check`：只读检查本地上传目录、metadata、演示资料和大文件/疑似真实资料风险。

演示资料均带有 “DEMO ONLY / non-real customer material” 声明，不包含真实客户图纸、真实 SOP 或真实生产资料。

## 上传体验

- 前端校验文件存在、资料类型、标题、版本、当前计划、文件格式和 30MB 大小限制。
- 支持 PDF、JPG、PNG、WEBP。
- 重复的 `productId + documentType + requiredForProcess + version` 会提示复核，但不直接阻断。
- 版本号建议使用 `Rev.A`、`Rev.B`、`Rev.C`，异常格式只提示不阻断。
- 上传成功后刷新资料包、文件健康、齐套性和当前搜索结果，并自动切到对应资料标签。
- 新上传资料卡片高亮 3 秒。

## 预览边界

- 无资料：提示上传真实资料。
- 演示资料：提示上传真实资料后替换预览。
- 不支持类型：提示可下载查看。
- 文件缺失：提示重新上传。
- PDF 或图片加载失败：提示下载查看或重新上传。
- 历史版本：提示不建议用于当前生产。
- 待确认版本：提示开工前复核。
- 大文件：提示预览可能较慢。

## 文件健康

`GET /api/documents/file-health` 在 V1.4 增加：

- 当前有效上传资料数。
- 待确认资料数。
- 历史/失效资料数。
- 不支持在线预览资料数。
- 大文件提醒数。
- 重复版本分组数。
- 每个资料项的版本分组、是否当前有效、是否历史、是否待确认、推荐动作。

## 现场模式

顶部状态栏新增“现场模式”。启用后会放大关键按钮和参数卡片，隐藏迁移类开发入口，但保留 Mock、未接 Sealos、离线演示等安全提示。

## 安全边界

- 不连接数据库。
- 不执行 migrate、db push、seed、db:readonly-check。
- 不上传真实客户资料。
- 不提交 `apps/api/storage/uploads`、metadata JSON 或 `.env.local`。
- 不使用非官方 Codex UI / Codex Android / Codex WebUI。
