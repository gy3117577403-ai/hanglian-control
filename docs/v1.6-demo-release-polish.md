# V1.6 演示版收口

## 目标

V1.6 不扩张业务主流程，重点把当前 Mock API + 本地文件上传/预览原型打磨成可现场演示、可讲解、可回归的平板演示版。

## 系统信息面板

顶部状态栏新增“系统信息”入口。面板展示：

- 系统名称与 V1.6 演示版标识。
- 运行模式：Mock 数据源、本地开发存储、支持局域网访问。
- Sealos、企业微信微盘、真实语音均明确标注未接入。
- 当前前端地址、API 地址、Swagger 地址。
- 安全状态和常用命令。
- “重置演示界面状态”按钮。

面板不会显示完整 `DATABASE_URL`，不会泄露本地绝对路径。

## 演示说明面板

顶部状态栏新增“演示说明”入口。内容按四步组织：

1. 启动演示。
2. 选择生产计划。
3. 查看资料。
4. 上传与追溯。

面板提供快捷按钮，可打开网络诊断、现场走查和上传资料。

## 演示状态重置

新增“重置演示界面状态”。该操作只清除浏览器中的演示 UI 状态：

- 现场走查勾选状态。
- 现场模式开关。
- 最近查询记录。
- 当前页签、scope、选中计划和 UI 偏好。

不会删除：

- 后端上传文件。
- `documents.json`。
- `audit-logs.json`。
- `storage/uploads`。
- 任何数据库或真实资料。

## 现场走查结果复制

现场走查面板新增：

- 复制走查结果。
- 重置走查。
- 全部标记为未完成。

复制失败时显示只读文本框，便于手动复制。走查结果只依赖浏览器状态，不依赖后端。

## 空状态/错误状态统一

新增统一组件：

- `WarmEmptyState.vue`
- `WarmErrorState.vue`

已接入生产计划为空、搜索无精确结果、资料为空、版本历史为空、审计记录为空、网络诊断失败、文件健康无数据和预览失败等场景。

## 演示版检查脚本

新增：

```bash
npm run demo:release-check
```

该脚本只读检查演示版文档、脚本、忽略规则、版本配置和 GitHub Actions workflow，不连接数据库，不启动服务，不写入文件。

## 当前边界

- 未接 Sealos PostgreSQL。
- 未接企业微信微盘。
- 未接真实语音识别。
- 未执行数据库连接或写库。
- 上传文件和 metadata 仍为本地演示流，禁止提交真实资料。
