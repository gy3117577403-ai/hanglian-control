# V1.7 演示数据管理与演示收口

## 阶段目标

V1.7 用于把 V1.6 演示版从“可演示”收口到“更容易交付演示、复盘和后续决策”。本阶段不连接 Sealos，不接企业微信微盘，不接真实语音，不执行数据库连接或写库操作。

## 已完成

- 顶部状态栏将系统信息、演示说明、网络诊断、现场走查、演示数据管理、演示前检查、演示资料说明、后续路线和迁移预览统一收进“演示工具”菜单。
- “现场模式”仍保持独立按钮，便于平板现场快速切换。
- 新增“演示数据管理”面板，说明 Mock 数据源、本地上传、本地 metadata、浏览器 UI 状态和演示资料目录。
- 新增“演示前检查”面板，只从前端触发健康检查和状态提示，不执行 npm 脚本，不连接数据库。
- 新增“演示资料说明”面板，说明 `demo-upload-assets` 合成资料和推荐上传走查流程。
- 新增“后续路线”面板，帮助选择继续 UI、合并 main、接 Sealos 测试库或接企业微信微盘。
- README 增加截图占位，不放真实客户资料和远程图片。

## 演示工具菜单

菜单入口：

1. 系统信息
2. 演示说明
3. 网络诊断
4. 现场走查
5. 演示数据管理
6. 演示前检查
7. 演示资料说明
8. 后续路线
9. 迁移预览
10. 重置演示界面状态

“重置演示界面状态”只清理浏览器 localStorage 中的界面状态，不删除上传文件、metadata、审计记录或数据库内容。

## 仍为 Mock

- 生产计划、产品资料包和搜索仍为 Mock / 本地原型数据。
- 文件上传仍使用本机开发存储。
- metadata 仍为本地 JSON，不提交 Git。
- Sealos PostgreSQL 未接入。
- 企业微信微盘未接入。
- 真实语音识别未接入。

## 演示前建议命令

```bash
npm run demo:assets
npm run demo:check
npm run file-flow:check
npm run demo:release-check
npm run security:check
npm run build
npm run check
```

这些命令均不应执行数据库连接、迁移、db push、seed 或真实写库。
