# V1.8 演示冻结候选版质量收口

## 阶段目标

V1.8 不继续堆复杂业务功能，重点做演示冻结前质量收口：UI 一致性、平板触控、上传/预览/版本/审计闭环、演示工具菜单、文案统一、演示边界和合并前检查。

## UI 一致性复核

- 保持暖色立体工业平板风。
- 主界面不回到黑色科技风。
- 顶部状态栏显示 V1.8 演示冻结候选版。
- 系统信息继续显示 Mock 数据源、未接 Sealos、未接企业微信微盘、未接真实语音。
- 弹窗、卡片、按钮、Message 和 Toast 保持明亮暖色。

## 平板触控复核

- 主按钮不低于 48px。
- 次级按钮不低于 44px。
- 上传区域、资料卡片、菜单项适合手指点击。
- 资料页签在 1280 宽度下可横向滚动。
- 弹窗在 1366 x 768 下内容可滚动，底部按钮可见。
- 不依赖 hover、右键或键盘快捷键。

## 核心业务闭环复核

- 选择生产计划、锁定产品、查看开工资料检查。
- 切换前段参数和后段资料。
- 上传 PDF 图纸、上传图片资料、拒绝不支持文件。
- 查看 PDF/图片预览和文件健康。
- 搜索上传资料。
- 查看版本历史、设置当前有效版本、查看审计记录。
- 组长确认、异常反馈、现场模式、网络诊断、现场走查。
- 演示数据管理、演示前检查、演示资料说明、后续路线选择。

## 冻结前验收面板

新增 `WarmFreezeChecklistDialog`，入口为“演示工具 → 冻结前验收”。

面板能力：

- 分组展示视觉与触控、生产计划、资料与预览、版本与追溯、演示工具、安全边界。
- 每项手动勾选。
- 进度保存到本机 `localStorage`。
- 支持复制验收结果。
- 支持重置。
- 不自动伪造通过。
- 不连接后端写库。
