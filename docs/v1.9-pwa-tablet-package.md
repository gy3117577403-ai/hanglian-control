# V1.9 PWA 平板演示试用包

## V1.9 目标

V1.9 将 V1.8 演示冻结候选版打磨成更像“安卓平板现场试用包”的形态，重点补齐 PWA 配置、平板安装提示、横屏提示、启动页、PWA 诊断、Windows 一键启动脚本和安装文档。

## PWA 配置

前端已在 `apps/tablet/vite.config.ts` 中集成 `vite-plugin-pwa`：

- 应用名称：线束车间资料管控。
- short_name：线束管控。
- display：standalone。
- orientation：landscape。
- start_url：`/tablet`。
- theme_color：暖琥珀色。
- background_color：暖米色。

API 和 `/api/files` 文件流不做离线缓存，避免现场看到过期资料。

## 图标生成

新增：

```bash
npm run pwa:assets
```

输出到：

```text
apps/tablet/public/pwa
```

图标为本地合成演示图标，不包含真实客户 logo。

## 启动页

新增 `WarmLaunchScreen`：

- 显示系统名称。
- 显示 V1.9 平板演示试用包。
- 显示 Mock 数据源、未接 Sealos、未接微盘、未接真实语音。
- 自动关闭，也可手动跳过。

## 横屏提示

新增 `WarmLandscapeGuard`：

- 检测竖屏或宽高不适合时显示提示。
- 用户可继续浏览。
- 关闭状态保存到本机 `localStorage`。

## 安装提示

新增 `WarmPwaInstallPrompt`：

- 监听 `beforeinstallprompt`。
- 支持浏览器安装时显示“安装到平板桌面”。
- 已以 standalone 运行时显示应用模式。
- 不支持安装时显示手动添加到主屏幕说明。
- 局域网 HTTP 下提示完整 PWA 建议使用 HTTPS。

## PWA 诊断

新增 `WarmPwaDiagnosticsDialog`：

- 当前访问地址。
- 当前 API 地址。
- 是否 HTTPS / localhost / 局域网 IP。
- Service Worker 支持和注册状态。
- 安装事件支持。
- standalone 模式。
- 横竖屏和屏幕尺寸。
- userAgent 简要信息。
- V1.9、Mock、未接 Sealos / 微盘 / 真实语音。

## Windows 启动脚本

新增：

```text
start-field-demo.bat
start-field-demo.ps1
```

用于启动 `npm run dev:lan`。脚本不写绝对路径，不连接数据库，不执行写库操作。
