# V2.0 生产计划与基础资料导入管理

V2.0 的目标是把演示系统从“只能依赖代码内 Mock seed”推进到“可通过 Excel / CSV 维护业务数据入口”。本阶段不接 Sealos，不接企业微信微盘，不接真实语音，不执行数据库连接或写库。

## 支持导入类型

| 类型 | 中文名称 | 作用 |
| --- | --- | --- |
| `production_plan` | 生产计划 | 导入本周/今日生产计划，自动补齐客户和产品 |
| `customer_product` | 客户产品 | 导入客户和产品主数据 |
| `front_parameter` | 前段参数 | 导入裁线、剥皮、端子、拉力、压接等参数 |
| `back_package` | 后段资料包 | 导入连接器、说明书、孔位图、SOP、成品图数量 |

## 流程

1. 在平板端打开“演示工具 → 数据导入中心”。
2. 选择导入类型。
3. 下载模板或使用 `demo-import-files` 中的演示文件。
4. 上传 Excel / CSV。
5. 先生成预览，查看有效行、警告行和错误行。
6. 没有错误行时应用导入；有警告行时需要二次确认。
7. 导入成功后刷新计划看板，导入计划可进入今日/本周列表、搜索和开工资料检查。
8. 导入记录写入本地 metadata，可在导入历史查看。
9. 回滚仅提供预览，不删除数据。

## 本地 metadata

V2.0 新增本地 metadata 文件：

- `apps/api/storage/metadata/import-records.json`
- `apps/api/storage/metadata/imported-business-data.json`
- `apps/api/storage/metadata/import-previews.json`

这些文件已加入 `.gitignore`，不要提交真实导入数据。

## 联动范围

- `GET /api/production-plans?scope=today|week` 可返回导入计划。
- `GET /api/production-plans/:id` 可返回导入计划详情。
- `GET /api/search` 可搜索导入客户、产品、前段参数、连接器、SOP、孔位图。
- `GET /api/production-plans/:id/readiness` 会基于导入参数和资料包重新计算。
- `GET /api/imports/history` 可查看导入历史。
- 审计记录会记录导入动作。

## 后续接 Sealos 的方式

后续接 Sealos PostgreSQL 时，将 `imports.service` 中的本地 metadata 写入替换为数据库事务：

- 客户、产品写入主数据表。
- 生产计划写入 `ProductionPlan`。
- 前段参数写入 `FrontProcessParameter`。
- 后段资料包写入 `BackProcessPackage`。
- 导入历史写入 `ImportRecord` 或审计表。

V2.0 阶段不执行 migrate、db push、seed 或任何真实写库命令。
