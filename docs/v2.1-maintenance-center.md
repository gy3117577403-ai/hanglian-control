# V2.1 资料维护中心

V2.1 在 V2.0 数据导入中心基础上增加“资料维护中心”，用于演示资料员或车间管理人员对本地 Mock / metadata 数据进行轻量维护、复核和留痕。当前阶段不连接 Sealos PostgreSQL，不接企业微信微盘，不接真实语音平台，不执行数据库连接或写库操作。

## 功能范围

- 顶部“演示工具”新增“资料维护中心”入口。
- 前端弹窗提供九个页签：概览、客户、产品、生产计划、前段参数、后段资料包、文件资料、复核队列、维护历史。
- 后端新增 `/api/maintenance/*` Mock API。
- 维护记录写入本地 `apps/api/storage/metadata/maintenance-records.json`，该文件已加入 `.gitignore`。
- 每次维护记录包含 `maintenanceId`、对象类型、对象 ID、动作、修改前、修改后、原因、操作人和时间。

## 支持维护的对象

| 对象 | 说明 |
| --- | --- |
| `customer` | 客户名称、简称、销售、状态、备注 |
| `product` | 产品名称、版本、类别、状态、备注 |
| `production_plan` | 计划日期、周计划编号、数量、状态、负责人 |
| `front_parameter` | 裁线长度、剥皮长度、端子型号、拉力标准、压接高度、图纸版本、参数状态 |
| `back_package` | 连接器、装配说明书、孔位图、SOP、成品图数量、版本、资料状态 |
| `document` | 文件标题、版本、状态、适用工序、设为当前有效版本 |
| `import_record` | 进入复核队列的导入警告记录 |
| `review_queue` | 待复核资料、低完整度计划、导入警告的处理记录 |

## 数据流

1. 用户在平板端打开“演示工具 → 资料维护中心”。
2. 前端调用 `/api/maintenance/summary` 加载统计。
3. 切换页签时调用对应列表接口。
4. 点击“维护”后提交 PATCH 请求。
5. 后端将修改合并到本地 Mock / metadata，并写入维护历史。
6. 主看板刷新生产计划，展示最新资料状态。

## 安全边界

- 不提交 `.env.local`。
- 不提交真实客户资料。
- 不提交 `apps/api/storage/uploads` 下的真实文件。
- 不提交 `apps/api/storage/metadata/*.json` 本地运行数据。
- 不打印或写入真实 `DATABASE_URL`。
- 禁止执行 `db:readonly-check`、`prisma migrate`、`prisma db push`、`prisma db seed`、`prisma:seed:test-db`。
