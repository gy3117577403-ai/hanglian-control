# V2.2 角色权限演示版

V2.2 在 V2.1 资料维护中心基础上新增本地 Mock 登录、角色切换、权限矩阵、菜单权限、按钮权限和后端 Mock 权限校验。

## 范围

- `/login` 本地 Mock 登录页，使用角色卡片进入系统。
- 当前用户状态保存在 `localStorage`，仅保存 mock token、用户和权限，不保存敏感信息。
- 顶栏显示当前用户、班组、角色，并支持切换角色、退出登录和查看权限说明。
- 菜单入口按权限显示，按钮按权限禁用或提示。
- 后端通过 `MockPermissionGuard` 校验写入类 Mock API。
- 审计、反馈、确认、上传、导入、维护等动作使用当前 Mock 用户作为操作人。

## Mock 角色

- `front_leader`：前段组长
- `back_leader`：后段组长
- `maintainer`：资料维护
- `process_engineer`：工艺
- `quality`：品质
- `admin`：管理员

## 安全边界

- 不接 Sealos PostgreSQL。
- 不接企业微信微盘。
- 不接企业微信登录。
- 不接真实语音识别。
- 不做真实组织架构。
- 不执行数据库连接、migrate、db push、seed 或任何写库操作。
