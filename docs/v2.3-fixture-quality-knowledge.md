# V2.3 治具异常质量知识库演示版

V2.3 在 V2.2 角色权限基础上新增三类现场知识库：治具库、异常库、质量标准库。目标是让前段/后段组长在选择生产计划后，能直接看到当前产品和工序相关的治具使用、常见异常处理、质量检验标准。

## 功能范围

- 平板主界面新增“现场知识库”区域，按当前计划、产品和前段/后段工序加载相关知识。
- 后端新增 `/api/knowledge` Mock API，数据来源为 seed + 本地 metadata。
- 资料维护中心新增“现场知识库”页，可查看、新增、维护状态和查看维护历史。
- 导入中心新增 `fixture`、`abnormal_case`、`quality_standard` 三类模板、预览和应用。
- 全局搜索结果新增 `fixture`、`abnormal_case`、`quality_standard` 类型。
- 权限新增知识库 view/create/update/history 权限。
- Prisma schema 新增未来实库模型，但本阶段不执行迁移、不连接数据库。

## 数据流

生产计划选择后：

1. 前端读取当前 `planId` 和 `activeProcess`。
2. 调用 `GET /api/knowledge/plan/:planId/summary`。
3. 后端从 Mock seed / 本地 metadata 过滤产品与工序。
4. 前端展示相关治具、异常案例、质量标准。
5. 维护或导入动作写入本地 metadata 和知识库维护历史。

## 本阶段安全边界

- 不接 Sealos PostgreSQL。
- 不接企业微信微盘。
- 不接企业微信登录。
- 不接真实语音识别。
- 不上传真实客户资料。
- 不执行 `db:readonly-check`、migrate、db push、seed。
- 本地知识库 metadata 已加入 `.gitignore`。
