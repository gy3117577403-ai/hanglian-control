# V2.6 现场统计看板

V2.6 将系统从“现场执行闭环”推进到“现场管理看板”。本阶段仍为 Mock / 本地 metadata 演示版，不连接 Sealos PostgreSQL，不接企业微信微盘，不接真实企业微信登录，不接真实语音识别，不执行数据库连接或写库操作。

## 目标

- 现场总览看板。
- 生产执行统计。
- 计划完成率统计。
- 数量报工统计。
- 异常停线统计。
- 质量异常趋势。
- 资料问题排行。
- 文件健康统计。
- 知识库复核统计。
- 今日 / 本周 / 本月 / 全部筛选。
- 前段 / 后段 / 通用 / 全部筛选。
- 复制统计摘要文本。

## 后端

新增 `apps/api/src/analytics` 模块：

- `GET /api/analytics/overview`
- `GET /api/analytics/production`
- `GET /api/analytics/quantity`
- `GET /api/analytics/exceptions`
- `GET /api/analytics/documents`
- `GET /api/analytics/knowledge`
- `GET /api/analytics/trends`
- `GET /api/analytics/rankings`
- `GET /api/analytics/summary-text`

Analytics controller 不直接读取 metadata，统计聚合集中在 service 和 helper 中。当前数据来源包括生产计划 Mock、执行记录 metadata、数量报工、异常反馈、资料记录、知识库记录、维护记录、导入记录和审计记录。

## 前端

新增 `WarmAnalyticsDashboardDialog`，从顶部“演示工具”菜单进入“现场统计”。看板包含：

- 总览指标卡。
- 计划状态环图。
- 完成率趋势折线图。
- 工序和班组分布。
- 不良率趋势。
- 异常类别排行。
- 资料问题排行。
- 知识库状态分布。
- 高风险异常排行。
- 统计摘要复制。

图表使用已安装的 `echarts` / `vue-echarts`，不引入新的大型依赖，不加载远程主题。

## 权限

新增权限点：

- `analytics.view`
- `analytics.production.view`
- `analytics.quality.view`
- `analytics.document.view`
- `analytics.knowledge.view`
- `analytics.summary.copy`

组长可查看生产和资料统计；资料维护可查看资料和知识统计；工艺可查看生产、资料、知识统计；品质可查看质量、资料、知识统计；管理员拥有全部权限。

## 演示数据

新增：

```bash
npm run demo:analytics
```

该脚本只生成 `apps/api/storage/metadata/demo-analytics-snapshot.json`，用于趋势图 fallback。该文件已加入 `.gitignore`，不会提交 Git。脚本不会覆盖 `execution-records.json`、`documents.json`、`knowledge-records.json` 等业务 metadata。

## 校验

新增：

```bash
npm run analytics-flow:check
```

该检查只读，不连接数据库，不执行 migrate、db push、seed 或任何写库操作。
