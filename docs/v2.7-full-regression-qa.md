# V2.7 全流程回归候选版

V2.7 是演示版进入后续路线前的总验收阶段，重点不是新增业务，而是把生产计划、资料查询、文件预览、版本审计、导入、维护、权限、知识库、执行闭环、统计看板和演示工具串成可检查、可复核、可复制报告的闭环。

## 目标

- 系统总回归检查。
- 数据一致性检查。
- 业务链路完整性检查。
- 权限矩阵回归检查。
- 演示准备检查。
- 生成演示验收报告。
- 输出 Sealos 接入前差距清单。

## 数据一致性检查

后端 `/api/system-qa/data-consistency` 和本地 `npm run data-consistency:check` 均只读检查 Mock / 本地 metadata。

## 业务链路检查

`/api/system-qa/business-flow` 检查生产计划、资料、导入、维护、知识库、执行闭环、统计看板和权限链路。

## 权限回归检查

`/api/system-qa/permission-regression` 按 Mock 角色输出可见菜单、允许操作、应禁止操作、缺失权限 warning 和过度授权 warning。

## 演示准备检查

`/api/system-qa/demo-readiness` 检查演示资料、导入文件、知识库文件、LAN 脚本、PWA 配置、文档、GitHub Actions、安全忽略和 Mock 提示。

## 验收报告

- 前端入口：演示工具 -> 全流程总验收。
- JSON：`GET /api/system-qa/acceptance-report`
- 可复制文本：`GET /api/system-qa/acceptance-report/text`
- 本地生成：`npm run acceptance:report`
- 输出文件：`docs/generated/acceptance-report-v2.7.md`
