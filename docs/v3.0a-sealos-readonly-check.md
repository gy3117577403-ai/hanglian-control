# V3.0A Sealos PostgreSQL 只读验证准备

## 阶段目标

V3.0A 只做 Sealos PostgreSQL 测试库的只读验证准备，不建表、不迁移、不 seed、不写库。当前业务数据仍来自 Mock seed 和本地 metadata，前端继续保持可演示状态。

## 本阶段允许

- 准备 `apps/api/.env.local`。
- 检查 `.env.local` 是否被 `.gitignore` 忽略。
- 在用户本机填写真实测试库连接串后，执行 `npm run db:readonly-check -w api`。
- 执行 Prisma schema 本地格式化、校验和 client generate。
- 生成 migration SQL preview。
- 生成 seed dry-run preview。
- 生成 V3.0A 只读验证报告。
- 执行 `npm run security:check`、`npm run build`、`npm run check`。

## 本阶段禁止

- 禁止连接生产库。
- 禁止打印完整 `DATABASE_URL`。
- 禁止提交 `.env.local`。
- 禁止执行 `npx prisma migrate dev`。
- 禁止执行 `npx prisma migrate deploy`。
- 禁止执行 `npx prisma db push`。
- 禁止执行 `npx prisma db seed`。
- 禁止执行 `npm run prisma:seed:test-db -w api`。
- 禁止任何 `insert`、`update`、`delete`、`truncate`、`drop` 等写库或破坏性操作。
- 禁止接入企业微信微盘、企业微信登录或真实语音平台。

## `.env.local` 必要字段

```env
NODE_ENV=development
PORT=3000
API_PREFIX=api

DATA_SOURCE=mock

DB_TARGET=test
DATABASE_URL=postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public

ALLOW_TEST_DB_CONNECT=true
ALLOW_PRISMA_WRITE=false
ALLOW_DESTRUCTIVE_DB_ACTIONS=false

SEED_MODE=dry-run
SEED_OPERATOR_ID=system-seed
SEED_OPERATOR_NAME=系统初始化

DATABASE_SSL_MODE=require
DATABASE_CONNECT_TIMEOUT_SECONDS=10
```

用户需要在本机文件中替换 `DATABASE_URL` 为 Sealos PostgreSQL 测试库连接串。不要把连接串发到聊天窗口，不要写入文档，不要提交到 Git。

## 命令顺序

```bash
npm run db:readonly-check -w api
npx prisma format --schema=apps/api/prisma/schema.prisma
npx prisma validate --schema=apps/api/prisma/schema.prisma
npx prisma generate --schema=apps/api/prisma/schema.prisma
npm run migration:validate -w api
npm run migration:preview -w api
npm run prisma:seed:dry-run -w api
npm run prisma:migration:sql-preview -w api
npm run sealos:readonly-check
npm run sealos:readonly-report
npm run security:check
npm run build
npm run check
```

如果 `DATABASE_URL` 仍为示例值，`db:readonly-check` 会安全退出，不连接数据库。

## 前端展示

平板端迁移预览弹窗显示 V3.0A 数据库安全状态，包括：

- 当前阶段。
- 数据源。
- 测试库目标。
- 脱敏连接串。
- 是否允许只读连接。
- 是否禁止写库。
- 是否关闭危险操作。
- `.env.local` 是否准备。
- 下一步操作提示。
