# V3.1 清理演示假数据与定制开发基线

## 目标

V3.1 暂停现场试运行配置方向，暂停 Sealos 数据库、企业微信微盘和真实语音接入。当前目标是把项目整理成干净的定制开发基线，等待用户提供真实界面和功能修改需求。

## 为什么清理演示假数据

演示数据适合验证能力，但不适合作为后续真实需求开发的默认内容。清理后，系统默认不展示假客户、假产品、假计划、假治具、假异常或假统计数据，避免把演示内容误认为现场资料。

## DEMO_DATA_MODE

后端支持：

- `empty`：默认模式，不加载业务演示 seed，页面显示空状态。
- `minimal`：保留系统必需数据，例如角色、权限、字典，不加载业务演示计划。
- `demo`：加载完整演示数据，后续需要演示时再打开。

当前默认：

```env
DEMO_DATA_MODE=empty
```

前端支持：

```env
VITE_DEMO_DATA_MODE=empty
```

## 重新生成演示数据

需要演示时可以重新执行：

```bash
npm run demo:assets
npm run demo:imports
npm run demo:knowledge
```

如需清理：

```bash
npm run demo:clean:dry
npm run demo:clean
```
