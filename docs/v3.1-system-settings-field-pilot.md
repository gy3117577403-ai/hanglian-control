# V3.1 系统配置中心与现场试运行配置

## 目标

V3.1 暂停 Sealos 接入线，先完成软件落地前必须具备的配置能力：系统字典、工位平板、显示模式、公告通知、使用反馈、试运行检查和配置审计。

当前仍为 Mock Repository / 本地 metadata：

- 未接 Sealos PostgreSQL。
- 未接企业微信微盘。
- 未接企业微信真实登录。
- 未接真实语音识别。
- 不执行数据库迁移、db push、seed 或写库。

## 系统配置中心

入口：平板端“演示工具 -> 系统配置中心”。

页签：

- 概览：显示 V3.1、工位数量、字典组、公告、待处理反馈。
- 基础配置：系统名称、车间、默认班组、默认角色、默认计划范围、现场模式。
- 字典配置：计划状态、资料状态、资料类型、异常等级、执行状态、反馈类型等。
- 工位配置：前段组长平板、后段组长平板、资料维护平板、现场演示平板。
- 显示配置：字体大小、卡片密度、现场模式、Mock 标签、技术提醒、暖色动效。
- 公告通知：试运行公告和系统维护提醒。
- 使用反馈：软件试运行问题闭环。
- 试运行检查：运行本地准备项检查。
- 配置历史：配置变更审计记录。

## 权限控制

新增 `settings.*` 权限点。前段/后段组长可查看公告、提交反馈、查看试运行检查；资料维护可查看配置和反馈；管理员拥有全部配置维护权限。

## 检查命令

```bash
npm run settings-flow:check
npm run field-pilot:check
npm run build
npm run check
```

禁止执行：

- `npm run db:readonly-check -w api`
- `npx prisma migrate dev`
- `npx prisma migrate deploy`
- `npx prisma db push`
- `npx prisma db seed`
- `npm run prisma:seed:test-db -w api`
