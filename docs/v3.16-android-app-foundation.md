# V3.16A Android APP 基础工程

V3.16A 将现有 Vue Tablet 生产构建打包进 Capacitor Android 原生壳，目标是先得到可在安卓平板手动安装的 Debug APK。此阶段不连接 PostgreSQL，不修改 Sealos，不接入企业微信微盘或真实语音平台。

## 基础信息

- APP ID：`com.hanglian.control`
- APP 名称：`线束资料工作台`
- Capacitor webDir：`apps/tablet/dist`
- Android 工程：`apps/tablet/android`
- 默认方向：`sensorLandscape`
- Debug 版本：`versionName=0.16.0-debug`，`versionCode=1600`

## 架构边界

- 原生 App 加载本地打包资源，不依赖远程 Web 页面。
- Capacitor 配置不包含正式 `server.url`。
- Web/PWA 的 `runtime-config.js`、`VITE_API_BASE_URL` 和自动 LAN/localhost 逻辑保持不变。
- 原生 App 优先读取 `VITE_NATIVE_API_BASE_URL`，缺失时显示 `APP 尚未配置服务器地址。` 并阻止 API 请求。
- Debug LAN API 仅通过本机忽略文件 `apps/tablet/.env.android.local` 配置，不提交 Git。
- Release 方向默认 HTTPS：`androidScheme=https`，主 Manifest 不开启 `usesCleartextTraffic`，`allowMixedContent` 默认 false。
- Debug 明文 HTTP 仅通过 `apps/tablet/android/app/src/debug/AndroidManifest.xml` 隔离开启。

## 原生能力

- Android 返回键：先关闭弹窗，再关闭资料查看器，再按图纸模块/产品/来源逐级返回，根页双击退出。
- 网络检测：使用 `@capacitor/network`，离线提示 `网络已断开，部分资料暂时无法加载。`，恢复提示 `网络已恢复。`。
- 状态栏与 Splash：原生环境设置暖色状态栏，首帧后隐藏 Splash，失败不阻塞启动。
- 安全区：仅在 `html[data-native-app="true"]` 下启用 safe-area inset，浏览器布局不受影响。
- 摄像头权限：已预备 `android.permission.CAMERA` 和非必需 camera feature；暂不申请录音权限。
- Service Worker：Android 构建模式禁用 PWA 注册，避免原生 WebView 受旧 PWA 缓存影响。

## 常用命令

```bash
npm run android:sync
npm run android:build:debug
```

Debug APK 预期路径：

```text
apps/tablet/android/app/build/outputs/apk/debug/app-debug.apk
```

本阶段不自动安装 APK，不执行 `adb install`，不创建正式签名证书。

## 检查命令

```bash
npm run android:check
npm run native-api-config:check
npm run android-back:check
npm run native-network:check
npm run build -w tablet
npm run security:check
npm run build
npm run check
```

## 后续接入 Sealos HTTPS

正式部署时应在云端 API 配置 HTTPS 域名，并在 API 生产环境 `CORS_ORIGINS` 中加入 `https://localhost` 作为 Capacitor WebView 来源。不要在 APK 或源码中写入数据库连接串、S3 密钥、企业微信 Secret、语音平台 Secret 或 Sealos Token。
