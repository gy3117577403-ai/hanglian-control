# V3.2 统一资料查询上传中心 + 删除密码锁

V3.2 调整产品方向：当前阶段不再把主页面拆成登录、角色、岗位专属页面，也不把生产执行闭环、统计看板、演示工具作为主流程。主页面聚焦成一个统一资料中心，用于资料查询、上传、预览、编辑、版本管理、回收站和删除保护。

## 功能范围

- 主页面：`/tablet` 直接进入“线束车间资料查询上传中心”，不要求登录。
- 查询：统一搜索图纸、SOP、孔位图、成品图、连接器资料、治具、异常案例和质量标准。
- 上传：支持 PDF、JPG、PNG、WEBP，单文件最大 30MB。
- 编辑：支持修改客户、产品编号、产品名称、产品版本、资料类型、标题、版本、状态、适用范围、关键词和备注。
- 版本：保留版本历史、当前有效版本和设为当前有效能力。
- 回收站：支持软删除、恢复、彻底删除。
- 批量操作：支持批量移入回收站、批量恢复、批量彻底删除。
- 审计：上传、编辑、删除、恢复、彻底删除写入本地审计记录。
- 文件健康：详情面板显示预览状态、文件名、文件大小和更新时间。

## 为什么取消登录和角色专属 UI

当前软件优先作为资料查询和资料管理工具落地。登录、权限、职位专属页面会增加现场使用成本，因此 V3.2 将主流程简化为所有资料功能集中在一个页面。原有权限系统和角色源码保留，后续若需要正式权限控制，可以重新启用。

## 删除密码锁

删除锁由后端保存本地 metadata，并只保存 bcrypt hash。前端只收集用户输入并提交给后端校验，不保存明文密码。

本地删除锁文件：

```text
apps/api/storage/metadata/delete-lock-settings.json
```

该文件已加入 `.gitignore`，禁止提交。

规则：

- 首次删除前需要设置删除密码。
- 密码至少 6 位。
- 删除和彻底删除必须输入删除密码。
- 连续错误 5 次锁定 5 分钟。
- 验证接口只返回 true / false，不返回 hash。
- 彻底删除仅允许删除 `apps/api/storage/uploads` 白名单目录中的本地上传文件。

## 删除类型

- 移入回收站：设置 deleted 标记、删除时间和删除人，文件不删除。
- 恢复资料：取消 deleted 标记，记录恢复时间和恢复人。
- 彻底删除：删除 metadata 记录；若是本地上传文件，仅删除 uploads 白名单目录内对应文件。
