# V3.3 主界面二次精简

## 目标

V3.3 将 `/tablet` 主页面收敛为“线束车间资料查询上传中心”。当前阶段不再把生产计划、岗位角色、演示工具、现场执行和统计看板作为主页面默认入口，页面聚焦资料查询、上传、预览、编辑、版本状态、回收站和删除密码锁。

## 主页面结构

- 左侧：资料中心入口、资料类型筛选、客户/产品/状态/来源筛选、回收站入口。
- 中间：资料快速查询、上传资料主按钮、排序、最近查询、批量操作、资料结果列表。
- 右侧：资料详情、预览、编辑、设为当前有效、删除、恢复、彻底删除、文件健康和版本历史。

## 本次隐藏内容

- 生产计划任务队列、计划详情、组长确认等生产计划模块不再出现在主页面。
- 登录权限、角色切换、职位专属 UI 不再出现在主页面。
- 演示工具、现场模式、现场执行闭环、统计看板不再出现在主页面。
- 顶部状态栏、Mock 权限、API 在线、未接 Sealos 等状态标签不再出现在主页面。

## 保留能力

- 上传资料入口保留并突出。
- 资料查询、预览、编辑、版本状态和设为当前有效保留。
- 回收站入口保留，并改为主列表模式，不再作为主页面弹窗入口。
- 删除密码锁保留，软删除、批量删除、彻底删除仍受密码保护。
- 后端 API、文件上传、资料预览、统一资料接口和已有模块源码保留。

## 当前仍未接入

- 未接 Sealos PostgreSQL。
- 未接企业微信微盘。
- 未接企业微信真实登录。
- 未接真实语音识别。
- 未执行数据库连接、迁移、db push、seed 或写库操作。
