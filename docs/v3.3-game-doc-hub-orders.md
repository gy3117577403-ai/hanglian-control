# V3.3 手游式资料库入口 + 订单驱动图纸库

## 目标

V3.3 将 `/tablet` 主页面改为现场资料调用工作台。主页面不做登录权限、职位专属 UI、复杂后台筛选、生产执行闭环或统计看板，只围绕“资料查询 + 上传补充资料 + 订单型号快捷打开资料”展开。

## 圆形功能入口

左上角使用圆形“资料库”入口，点击后展开三项功能：

- 图纸库
- 连接器参数
- 治具参数

入口采用暖色立体风格，类似手游功能入口，不占用大面积空间。

## 今日 / 本周订单

左侧固定显示今日订单和本周订单。订单使用演示假数据，不包含真实客户资料。

订单字段包括产品型号、客户名称、状态和完成按钮。点击产品型号会自动切换到图纸库，并打开该产品型号的图纸资料详情。点击完成后，订单从今日/本周待办列表移除，并进入订单总览的已完成列表。

## 图纸库层级

图纸库按以下层级递进：

1. 客户列表
2. 产品型号列表
3. 产品图纸详情主页
4. 模块详情页
5. 大图 / 资料查看页

从订单或搜索结果进入详情后，返回时保留上一层位置和滚动状态，不直接回到首页。

## 图纸详情六大模块

产品图纸详情固定展示：

- 原图
- SOP 指导书
- 成品图
- 辅料规格
- 注意事项
- 配套工装

模块卡片固定高度，不被多图撑开。多图模块主页只显示首项和数量，点击“查看全部”进入模块详情页，再查看全部图片、PDF 或资料卡片。

## 连接器参数

连接器参数为独立搜索模块，不走客户/产品层级。当前字段包括连接器型号、端子型号、孔位数、颜色、适配线径、厂家、锁止方式、适用工序、状态和备注。

## 治具参数

治具参数为独立搜索模块，不走客户/产品层级。当前字段包括治具编号、治具名称、治具类型、适用产品、适用工位、适用工序、存放位置、状态、保养周期和备注。

## 当前功能范围搜索

顶部搜索框会根据当前功能切换搜索范围：

- 图纸库：搜索客户、产品型号、图纸、SOP、成品图
- 连接器参数：搜索连接器型号、端子型号、孔位数、厂家
- 治具参数：搜索治具编号、治具名称、工位、适用产品

## 上传方式

保留顶部上传资料按钮，并新增模块内上传入口。

从模块内上传时自动带入客户、产品型号和模块类型；从顶部上传时可手动选择客户、产品型号和模块类型。当前阶段写入 Mock 状态，后续真实逻辑中原图默认来自企业微信微盘，SOP、成品图、辅料规格、注意事项和配套工装可在软件内补充并保存到云端数据库或文件服务。

## 删除密码

当前本地默认删除密码为 `123`，用于现场演示和本地验证。后端只保存 bcrypt hash，不保存明文密码；前端不保存密码，日志不打印密码。后续可在设置中修改删除密码。

## 后续导入方向

后续 Excel 导入第一步只导入产品型号；真实总数据源计划接企业微信微盘，微盘默认自带原图。再次打开同一产品型号时，系统自动带出已上传或已同步的资料信息。
